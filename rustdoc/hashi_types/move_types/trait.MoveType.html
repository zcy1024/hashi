A Rust mirror of a Move struct, identified by its defining package version, module, and name.

const PACKAGE_VERSION: u64 = 1

The hashi package version that first defined this struct. A type keeps its defining package’s address through upgrades, so matches resolves this version to the one address the struct tag must carry — types added in an upgraded package declare the version that introduced them.

Source

The number of type parameters the struct tag must carry.
